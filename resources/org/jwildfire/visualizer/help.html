Music Visualizer

This module transforms audio input into real-time graphical visualizations. It supports multiple rendering engines, from simple spectrum analysis to complex 3D raymarching.

Controls

  • Start/Stop Capture: Toggles audio input processing. Ensure you have selected a valid device.
  • Device: Select the audio input source (e.g., Microphone, Line-In, or "Stereo Mix" for system audio).
  • Sensitivity: Adjusts how responsive the visualization is to sound levels. Higher values make it more reactive to quiet sounds.
  • Gain: digital amplification of the input signal.

Visualizer Engines

The integrated canvas shows a basic spectrum/waveform preview. For full-screen, high-performance visuals, use the Launch buttons:

  • OpenGL: Launches a hardware-accelerated window using custom OpenGL shaders.
  • projectM: Integration with the open-source implementation of MilkDrop. Supports `.milk` presets.
  • Raymarching: Uses advanced raymarching techniques to render 3D fractals (Mandelbulb, Spheres) that react to music.
Performance Note: Running multiple visualizers simultaneously or alongside heavy rendering tasks may impact system performance. Raymarching requires a capable GPU.

Troubleshooting

If no audio is detected, check your OS sound settings and ensure JWildfire has permission to access the microphone. On Linux, ALSA/PulseAudio configuration may be required.
