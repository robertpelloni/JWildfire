Electric Sheep Integration

This module allows you to interact with the Electric Sheep distributed computing project directly from JWildfire.

Browser Tab

The main interface for browsing and interacting with the "flock".

  • Refresh: Connects to the server to fetch the latest list of active sheep.
  • Sheep List: Displays available genomes. Select one to preview or download.
  • Preview Area: Shows a rendered image of the selected sheep.
  • Download: Downloads the genome file (.flame) to your local cache.
  • Render Preview: Uses JWildfire's internal engine (GPU if available) to render a high-quality still of the sheep.
  • Edit in JWildfire: Loads the sheep's genome into the main JWildfire editor, allowing you to modify, mutate, or render it at high resolution.

Settings Tab

Configure your connection to the Electric Sheep network.

  • Nickname: Your username on the server. Default is jwildfire_user.
  • Server URL: The entry point for the server API. Default is the community server.
  • Cache Directory: Where downloaded genomes are stored.
Note: Some server features may require a valid account or specific permissions. If connection fails, check your internet connection and SSL settings.

About Electric Sheep

Electric Sheep is a collaborative abstract artwork founded by Scott Draves. Ordinary computers sleep and dream, creating the "sheep" (fractal animations). JWildfire is compatible with the "Flame" algorithm used by Electric Sheep.
